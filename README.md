One sentence a house cat would say in its own defence, five seconds after
sweeping a glass off the table — no apology, no confession, just the cat's
own logic:

> I caught the glass plotting against my dinner, so I removed it before it could strike — you're welcome.

103 characters. `main.ts` writes exactly that sentence to `entry.txt`
(no trailing newline), deterministically, with no network, clock or
randomness.
